# 📊 Adidas Sales Performance Dashboard

An interactive Excel dashboard designed to analyze and visualize Adidas sales performance, track key performance indicators (KPIs), and uncover actionable business insights between 2023 and 2025.

## 🚀 Project Overview
This project transforms raw sales data into a structured, highly visual interactive dashboard. It provides stakeholders with a comprehensive view of revenue streams, profit margins, demographic preferences, and regional performance to support strategic decision-making.

---

## 📈 Key Performance Indicators (KPIs)
The dashboard provides an immediate snapshot of overall business health[cite: 7]:
* **Total Sales:** 306,015[cite: 7]
* **Total Profit:** 85,070[cite: 7]
* **Profit Margins:** 29%[cite: 7]
* **Total Quantity Sold:** 3,550 units[cite: 7]

---

## 🔍 Key Insights & Visualizations
The dashboard incorporates multiple analytical views[cite: 7]:
* **Year-Over-Year Sales:** Tracks sales growth across 2023, 2024, and 2025[cite: 7].
* **Category Performance:** Analyzes sales distribution across Footwear, Apparel, and Accessories[cite: 7].
* **Demographic Breakdown:** Compares sales volume between Men's, Women's, and Other categories[cite: 7].
* **Top 10 Products:** Highlights best-selling items like the Predator Freak, Ultraboost, and Copa Sense[cite: 7].
* **Sales Channels:** Breaks down revenue generated via Online, Retail, Outlet, and Wholesale channels[cite: 7].
* **Regional Sales:** Maps sales performance across key Middle Eastern markets: Egypt, Iraq, Oman, KSA, and Lebanon[cite: 7].
* **Trend Analysis:** Features line and combo charts monitoring stable vs. changing profit margins and monthly sales vs. profit performance[cite: 7].
* **Pareto Analysis:** Identifies the core product categories responsible for 80% of total sales[cite: 7].

---

## 🛠️ Tools & Features Used
* **Microsoft Excel:** Primary tool for data manipulation and visualization.
* **Pivot Tables & Pivot Charts:** Used to aggregate raw data and build dynamic visual components.
* **Interactive Slicers:** Allows users to filter the entire dashboard by Year, Category, and Region[cite: 7].
* **Custom Formatting:** Implemented KPI cards and tailored color palettes for a professional UI.
