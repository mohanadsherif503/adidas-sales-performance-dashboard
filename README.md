# 📊 Adidas Sales Performance Dashboard

An interactive Excel dashboard designed to analyze and visualize Adidas sales performance, track key performance indicators (KPIs), and uncover actionable business insights.

---

## 🖼️ Dashboard Preview
![Adidas Dashboard](Adidas%20Dashboard.png)

---

## 🚀 Project Overview
This project focuses on transforming raw sales data into a clean, structured, and visually appealing interactive dashboard. The goal is to provide stakeholders with a clear overview of total revenue, profit margins, units sold, and discount impacts.

---

## 🛠️ Tools & Technologies Used
* **Microsoft Excel:** Data cleaning, transformation, and dashboard design.
* **Power Query:** Data extraction, transformation, and loading (ETL) pipeline.
* **Pivot Tables & Pivot Charts:** Aggregating data and building dynamic visual components.
